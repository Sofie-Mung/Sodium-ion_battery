## 0. 연구 한 문단

O3형 Na 층상 양극재(108원자 셀 = Na27 TM27 O54)에서 충전(탈소듐) 시 TMO2 슬랩 gliding
(O3→P3)을 억제하는 고엔트로피 조성을 MLIP 전수 스크리닝 + DFT 검증으로 찾는다.
두 축: **축① 합성 가능성**(Ehull_eff, T*), **축② gliding 억제**(dE, ddE, x*).
전수 7,073 조성, MLIP은 ORB-v3 conservative **mpa**(화폐 = MP PBE+U, MPStaticSet과 동일 은행),
대조 모델 MACE, DFT 검증은 VASP MPStaticSet(GGA+U Ni 6.2 / Mn 3.9).

## 1. 부호·방향 규약 (오독 최다 지점 — 항상 여기로 돌아올 것)

- dE = [E(P3) − E(O3)]/27 [meV/f.u.]. **dE > 0 = O3 승리(좋음)**, dE < 0 = P3(gliding).
- ddE = dE_desod − dE_pris. **클수록(덜 음수) 좋음**.
- 판정: dE > +δ → O3, dE < −δ → P3, |dE| ≤ δ → AMB(판정 유보, 후보 제외).
  δ = max(σ_vac, |dE_ORB − dE_MACE|, 5.0) — x별 독립 산출.
- score = rank(ddE↓) + rank(Ehull_eff↑) + rank(dV_nat↑). **낮을수록 상위**, top-30 추출.
  관문 3개: Ehull_eff < 0.10 eV/atom, dE_pris > +5, suppressed(verdict@x052 == O3).
- x 태그: x100/x081/x067/x052 = Na 27/22/18/14 = x 1.0/0.8148/0.6667/0.5185.
- 앵커 3종(방향 시험 전용, MAE 시험 아님):
  HOST = NaNi0.5Mn0.5O2 (실험: O3→P3 전이, V≈3.1 V) / Ti03 (억제) / HEO = Zhao 2020 (지연).

## 2. 완료 상태

**v3 (2-point)**: 7,073 조성 전수 스크리닝 완료, 관문 통과자 채점 → top-30 확정, top-5 DFT 진행.
**v4 (이번)**: Pass 1–3 완료. 두 가지 변경이 들어감.

- **변경 A — dV 정밀화**: a²c 로그미분 근사(각도 고정 + 소변형 가정) → **V = |det L| 삼중곱 정확식**.
  신규 컬럼: dA_pct(면내 = |a×b|), dh_perp_pct(층간 = V/A, 기울기 면역), vm_strain(von Mises
  모양 변형, F = L_d(L_p)^-1 → E = (F^T F − I)/2 의 편차부), d_inter_pris, dV_legacy(비교용).
  검산 항등식: (1+dV/100) = (1+dA/100)(1+dh/100).
- **변경 B — Na 4-point**: x081/x067 추가(짝지은 빈자리 5샘플, O3/P3 동일 패턴).
  신규: x별 dE/σ_vac/δ/verdict, x_star_class, x_star_lo/hi/mid, V_seg 3개, Ef_x081/x067, convexity_flag.
- **채점 정의는 불변** (v3 비교 가능성 유지). 신규 량은 전부 보고 컬럼.

결과 파일: results_v3.csv (7,073행 — 파일명은 v3이지만 **v4 컬럼 포함된 최신 산출물**).

| vm_strain | −0.198 (n=3,854) | −0.132 | −0.146 | −0.173 |

## 4. 열린 항목 (다음 대화에서 이어갈 것)

  차이 < δ면 "역전"이 아니라 "동률". 이 판정이 스크리닝 해석 전체의 게이트.

### 4-2. x059 추가 제안 (구간 해상)

앵커 3종 + top-50에만 x059 추가하면 지배 구간이 갈라져 HOST/Ti03/HEO 순서 해상 가능.

### 4-3. 미결 결정 (사용자 몫)
- dV_legacy 컬럼 제거 승인 (회귀 리포트 확인 후)
- x*, vm_strain의 점수 승격 여부 (top-30 이동량 보고 후 결정)
- nonmonotonic 3행 처리 방침
- capacity 회계에서 V/Cu 포함 여부 (미확정이라 현재 점수 밖)

### 4-4. 파인튜닝 트랙 (대기)
top-5 DFT 수렴 → **F0 진단**(고정 기하 static으로 연화계수 c + 부호 일치율).
부호 5/5 일치 + 기울기 균일 → 파인튜닝 **불필요**(c만 기록, 순위합은 연화에 구조적 면역).
부호 뒤집힘/산포형 → F1(조성 24 × 프레임 10, glide 중간상·±3% 변형 포함) → F3(lr 1e-4,
E:F:S = 0.1:100:0.1) → F4 A/B(HEO_ORB_CKPT로 재실행, 망각 감시) → F5(합격 기준 4개).
**앵커는 학습에서 영구 제외.**

### 4-5. 모델 대안 탐색
전면 교체 아님. (a) 대조 슬롯을 상위 등변 모델로 승격, 또는 (b) top-500만 계층 재채점.
관문: MP 화폐 체크포인트(-OAM/-MPA 계열), torch-sim/conservative 지원, 앵커 방향 시험 통과.

## 5. 원리 학습 트랙 (계단식 설명 → 그림 → 파이프라인 연결 → 논문 1편 + 가이드 질문 3개 → 정산)
