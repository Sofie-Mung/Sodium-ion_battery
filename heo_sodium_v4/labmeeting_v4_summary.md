# 랩미팅 정리 — HEO Na 층상 양극재 MLIP 스크리닝 v4
### Na 4-point 탈소듐 + 격자 변형 분해 결과

> 작성일: 2026-09-11 | 모델: ORB-v3 conservative (mpa) | 데이터: `heo_v4/results/results_v3.csv`, `top30_v3.csv`
> 한 줄 요약: **상위 후보들은 Na가 67%까지 빠져도 O3 구조를 유지하고, 67%→52% 구간에서 일제히 gliding이 일어난다. 52%까지 버티는 조성은 단 1개다.**

## 0. 배경을 모르는 사람을 위한 3분 설명

### 우리가 풀려는 문제
- 나트륨 이온 전지 양극재 **O3형 Na층상 산화물(NaₓTMO₂)**은 충전 중 Na가 빠지면 TMO₂ 층이 옆으로 미끄러져(**gliding**) O3 → P3 구조로 바뀐다.
- 이 상전이는 부피 변화·전압 계단·용량 감소의 원인이므로, **gliding을 늦추거나 막는 조성**을 찾는 것이 목표다.
- 후보는 전이금속 자리를 5종 이상으로 섞은 **고엔트로피 조성(HEO)**이며, 총 7073개를 열거했다.

### 어떻게 계산했나
- 108원자 셀(Na27 TM27 O54)에서 O3와 P3 구조를 각각 만들고, MLIP(ORB-v3)로 에너지를 계산한다.
- **dE = E(P3) − E(O3)** [meV/f.u.]. **dE > 0이면 O3가 더 안정(좋음)**, dE < 0이면 P3가 이겨서 gliding이 일어난다.
- Na를 빼는 방식: 27개 중 5개 / 9개 / 13개를 제거 → x = 1.00 / 0.81 / 0.67 / 0.52 네 점. 빈자리 배치는 5가지를 무작위로 뽑되 O3와 P3에 **같은 패턴**을 써서 비교가 공정하도록 했다.

### 판정 규칙 (O3 / P3 / AMB)
- 빈자리 배치 5개 사이의 에너지 편차 σ_vac을 잡음으로 보고, 문턱 **δ = max(σ_vac, 5 meV/f.u.)**을 x마다 따로 정한다.
- dE > +δ → **O3** (gliding 억제), dE < −δ → **P3** (gliding 발생), |dE| ≤ δ → **AMB**.
- **AMB(ambiguous)는 "판정 유보"**다. O3와 P3의 에너지 차이가 잡음보다 작아서 어느 쪽이 이겼다고 말할 수 없다는 뜻이며, 오류가 아니다. 샘플을 늘리면 대부분 풀린다.

## 4. 핵심 발견 5가지

### 발견 1. gliding은 x = 0.67 ~ 0.52 구간에 몰린다
- top500의 판정 패턴(x 1.00 / 0.81 / 0.67 / 0.52):

| 패턴 | 개수 | 뜻 |
|---|---|---|
| O3 / O3 / O3 / P3 | **442** | 0.67까지 버티다 0.52에서 gliding |
| O3 / O3 / AMB / P3 | 41 | 0.67에서 이미 흔들림 |
| O3 / O3 / O3 / AMB | 7 | 0.52에서도 아슬아슬 |
| O3 / O3 / P3 / P3 | 2 | 0.67에서 이미 gliding |
| O3 / O3 / O3 / O3 | **1** | 끝까지 억제 (tier 0) |
| 기타 (비단조 등) | 7 | 잡음 재검토 대상 |

- x = 0.67에서 O3 여유(dE − δ)의 중앙값은 **27 meV/f.u.** 로 넉넉하다. 5% 분위수만 음수다.
- 앵커 HOST(NaNi₀.₅Mn₀.₅O₂)도 같은 구간에서 넘어간다. 실험(Komaba 2012)에서 P3가 x ≈ 0.5~0.6에 나타나는 것과 방향이 맞는다.
- **쉽게 말하면**: 우리가 고른 상위 후보들은 "Na를 1/3 빼는 것까지는 안전하고, 그 다음 1/6을 더 빼면 거의 다 미끄러진다."

### 발견 2. dE(x)는 직선이 아니라 위로 볼록하다
- x = 0.67에서 실제 dE가 2점 선형 보간값보다 평균 **+11 meV** 높다. x = 0.81에서는 −5 meV.
- 즉 O3 안정성은 초반에 천천히 줄다가 0.67 이후 급격히 무너진다.
- 결과적으로 v3의 2점 x_cross는 전이를 **약간 이르게** 예측했고, 4점 구분선형 교차점(x_cross_4pt)과의 순위 상관은 Spearman **0.49**에 그친다. → 내부점은 실제로 새 정보를 담고 있다.
- 단, 현재 csv의 x_star_mid는 0.593과 0.741 두 값뿐이라 변별력이 거의 없다. 연속값 x_cross_4pt는 이번 분석에서 계산한 참고값이며 점수 승격은 별도 결정 사항.

### 발견 3. 도펀트 규칙: Ca는 gliding을 앞당기고, Mg는 늦춘다
x = 0.67에서의 dE 중앙값 비교 (top500):

| 원소 | 포함 조성 수 | 포함 시 dE_x067 | 미포함 시 | 통계 (Mann-Whitney p) |
|---|---|---|---|---|
| **Ca** | 139 | **26.9** | 38.7 | 3 × 10⁻¹⁹ (매우 유의) |
| **Mg** | 265 | **38.8** | 34.3 | 6 × 10⁻⁸ |
| Zr | 135 | 32.5 | 37.5 | 0.008 |

- 해석: Ca²⁺처럼 큰 이온이 TM 자리에 들어가면 층간이 넓어져 층 슬라이딩 장벽이 낮아지는 것으로 보인다. Mg²⁺(작은 2가 이온)는 반대로 O3를 붙잡아 준다.
- 실제로 top30에서 유일하게 0.67에서 먼저 흔들린 B_Mg-Ti-Mn-Sn-Ca 는 Ca 포함 조성이다.

### 발견 4. 엔트로피가 gliding을 늦춘다는 증거는 없다 (0 K 기준)
- 배치 엔트로피 S_conf와 dE_x067의 상관: ρ = **−0.04** (없음).
- S_conf와 vm_strain(모양 변형)의 상관: ρ = **−0.28** (약한 완충 신호).
- HEO 앵커(Zhao 2020의 5-TM 고엔트로피)도 HOST와 **같은 구간**에서 전이하고, x = 0.67에서의 dE는 오히려 HOST보다 낮다(33.7 vs 40.3).
- Nat. Commun. 2025의 "엔트로피가 이방 변형을 완충한다"는 주장은 **변형 쪽에서만 약하게** 보이고, **상전이 쪽에서는 지지되지 않는다**. 실험에서 보이는 "전이 지연"은 0 K 에너지 이외의 요인(속도론, 온도, 결함)일 가능성이 크다.

### 발견 5. 스칼라 부피 변화(dV)는 구조 붕괴 위험을 가린다
- x = 0.52에서 500개 **전부**가 면내 수축(dA < 0) + 층간 팽창(dh > 0)이 **서로 상쇄**되는 사분면에 있다.
- 중앙값: dA **−5.6%**, dh **+5.1%**, 그런데 합친 dV는 **−0.8%** 밖에 안 된다.
- |dV| < 1%로 "안전해 보이지만" 모양 변형 vm_strain > 0.05인 조성이 **218개**다. → 부피만 보면 입자 균열 위험을 놓친다.
- 구간별 변형과 전압:

| 구간 | vm_strain (중앙값) | dh (중앙값) | V_seg (중앙값) |
|---|---|---|---|
| 1.00 → 0.81 | 0.010 | +0.3% | 2.66 V |
| 0.81 → 0.67 | 0.016 | +0.6% | 2.83 V |
| 0.67 → 0.52 | **0.054** | **+5.1%** | **3.09 V** |

- gliding, 층간 팽창(3배 이상 급증), 전압 점프(중앙값 +0.23 V)가 **모두 마지막 구간에서 동시에** 일어난다.
- x 방향 hull은 492/500이 convex(고용체 경향), 8개만 mixed/concave(2상 공존 후보).

## 7. 한계 (발표 때 먼저 말할 것)

1. **격자 분해능**: 4점이라 x_star_mid는 0.593 / 0.741 두 값뿐. top500이 2점 x_cross로 선발되어 대부분 마지막 구간에 몰리는 **선택효과**가 있다.
2. **샘플링 잡음**: 빈자리 5샘플이라 δ > 15 meV인 조성이 108개. AMB 상당수와 비단조 9행은 샘플 부족 탓. dE 정의가 5샘플의 **최소값**(pessimistic)이라 잡음이 클수록 P3 쪽으로 편향된다.
3. **0 K 정적 에너지**: 온도·속도론·결함이 없다. 실제 사이클 수명은 대리 지표(vm_strain, dh, 전압 점프)로만 추정.
4. **MLIP 신뢰도**: ORB 단일 모델. MACE 대조 dE는 내부점에 없어 δ가 σ_vac과 바닥값으로만 정해졌다. DFT 검증 전까지는 "방향"만 믿는다.
5. **점수 정의**: 현재 score = rank(x_cross) + rank(Ehull_eff) 2항. 4점 지표와 변형 지표는 점수에 없다.

## 부록 A. 용어 한 줄 정리

| 용어 | 뜻 |
|---|---|
| O3 / P3 | Na 자리가 팔면체(O) / 프리즘(P) 배위, 숫자는 층 반복 주기. O3 → P3 전이 = gliding |
| dE | E(P3) − E(O3), 양수면 O3 안정 (좋음) |
| ddE | dE_desod − dE_pris, 클수록(덜 음수) 좋음 |
| δ (delta) | 판정 문턱 = max(빈자리 잡음 σ_vac, 5 meV/f.u.) |
| AMB | 판정 유보. \|dE\| ≤ δ |
| x_cross | dE가 0을 지나는 x (2점 선형). 작을수록 늦게 전이 = 좋음 |
| x_star_lo / hi | 4점 판정으로 특정한 전이 구간 |
| Ehull_eff | 합성 가능성 (0.10 eV 이하만 통과), T* = 엔트로피 안정화 온도 |
| dA / dh / vm_strain | 면내 면적 변화 / 층간 거리 변화 / von Mises 모양 변형 |
| V_seg | 구간별 평균 전압 (계단 곡선) |
| Ef_x081 / Ef_x067 | x 방향 hull 상 형성에너지. 음수 = 고용체 안정 |
| tier 0 / 1 | 0.52에서 O3 유지 / 그 외 |
