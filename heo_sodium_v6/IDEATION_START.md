# IDEATION_START — 문헌 탐색과 아이디어 논의용 시작 문서

> 새 대화를 시작할 때 이 문서를 먼저 붙여넣는다.
> 목적: 논문을 읽고, 이 프로젝트에서 개선하거나 새로 시도할 만한 방향을 사용자가 직접 생각해 내는 것.
> Claude의 역할은 문헌을 찾아 주고, 사용자의 생각을 검토하고, 반론을 제기하는 것이다. 아이디어를 대신 정해 주는 것이 아니다.

## 0. 프로젝트 한 문단

O3형 Na 층상 양극재(108원자 셀 = Na27 TM27 O54)에서, 충전(Na를 빼는 과정) 중 전이금속 산화물 층이 미끄러져
O3 구조가 P3 구조로 바뀌는 현상을 억제하는 조성을 찾는다. 방법은 여러 원소를 섞는 고엔트로피 설계이고,
7,073개 조성을 기계학습 원자간 퍼텐셜(MLIP)로 전수 계산한 뒤 상위 30개를 DFT로 검증한다.
**고엔트로피는 목적이 아니라 수단이다. 목적은 수명(구조 안정성)과 합성 가능성이다.**

## 1. 지금까지 만든 것

| 단계 | 내용 | 상태 |
|---|---|---|
| 전수 스크리닝 | ORB-v3 mpa로 7,073 조성. Na 함량 4점(x = 1.0, 0.81, 0.67, 0.52)에서 O3와 P3의 에너지 비교 | 완료 |
| 채점 | 미끄러짐 억제(ddE) + 합성 가능성(Ehull_eff) + 부피 변화(dV)의 순위합 → top-30 | 완료 |
| 모델 벤치마크 | uMLIP 12종이 top-30을 같은 조건으로 재계산 | 실행 중 (2026-10-01) |
| DFT 검증 | top-30 + 앵커 2종, VASP (MP 설정, GGA+U) | 계산 중 |

파이프라인이 조성마다 내놓는 값: 각 x에서의 dE와 상 판정, 전이가 일어나는 x 구간, 구간별 전압과 평균 전압,
Na 삽입 에너지, 부피·면내 넓이·층간 거리 변화, 모양 변형(von Mises), Ehull과 유효 Ehull, 배열 엔트로피.

부호 규약: dE = [E(P3) − E(O3)]/27, 단위 meV/f.u. **dE > 0이면 O3가 안정(좋음).**

## 2. 이미 알고 있는 것과 풀리지 않은 것

- 거의 모든 조성이 같은 구간(x = 0.52–0.67)에서 전이한다. 4점 격자로는 조성 간 차이를 가르지 못한다.
- 0 K 계산에서는 HEO 앵커가 HOST보다 전이가 늦다는 신호가 나오지 않는다 (ORB와 MACE가 일치). 실험(Zhao 2020)과 어긋나는 지점이고, 이유는 아직 설명되지 않았다.
- 배열 엔트로피와 모양 변형 사이에 약한 음의 상관이 있다 (ρ ≈ −0.15~−0.2). 효과는 작다.
- 용량 회계가 미확정이라 채점에 들어가 있지 않다. 비활성 원소를 넣으면 안정해지지만 용량이 줄어드는 대가를 지금은 보지 않는다.
- 충전 깊이가 x = 0.52에서 멈춘다. 그 아래 구간의 상전이는 다루지 않는다.

## 3. 아이디어 씨앗 (출발점일 뿐, 정답 아님)

사용자가 논문을 읽으며 판단할 후보들이다. 각 항목의 "알려진 바"는 일반적인 배경 지식 수준이고 문헌으로 확인되지 않았다.

| 방향 | 무엇에 영향 | 지금 파이프라인과의 거리 |
|---|---|---|
| 용량 회계 | 에너지 밀도 | 계산 불필요. 조성에서 활성 원소 수만 세면 됨 |
| Na 이온 확산 | 고속 충방전. O3는 P3보다 Na 이동이 느리다고 알려져 있어, 미끄러짐 억제의 대가일 수 있음 | MLIP 분자동역학 또는 이동 장벽 계산. 새 코드 필요 |
| 더 깊은 충전 구간 | 고전압 용량과 수명 | x 격자 확장. 구조 템플릿 추가 필요 |
| 전이 구간 해상도 | 조성 간 변별 | Na 16개(x = 0.59) 한 점 추가 제안이 이미 있음 |
| 유한 온도 효과 | 0 K에서 안 보이는 HEO 지연을 설명할 가능성 | 진동·배열 엔트로피 항. 방법론부터 조사 필요 |
| 산소 안정성 | 고전압 산소 방출, 안전성 | 산소 빈자리 생성 에너지 |
| 전이금속 이동 | 전압 감쇠, 비가역 용량 | 전이금속이 Na 층으로 넘어가는 에너지 |
| Na/빈자리 배열 | 전압 곡선의 계단 | 빈자리 5샘플의 산포를 이미 계산함. 해석만 추가 가능 |
| 국소 왜곡 (얀-텔러) | 수명 | DFT 자화 감사에서 산화수가 나오면 연결 |
| 미끄러짐의 운동학 | 열역학적으로 P3가 안정해도 장벽이 높으면 전이가 느림 | 미끄러짐 경로의 에너지 장벽. 새 계산 |
| 공기·수분 안정성 | 실용화 | 계산으로 다루기 어려움. 문헌 조사 위주 |
| 원가 | 소듐 전지의 존재 이유 | 조성에서 바로 계산 가능 |

## 4. 논의 방식 (Claude에게)

1. **사용자가 먼저 생각을 말하게 한다.** 답을 바로 주지 말고, 사용자의 가설을 듣고 그 가설이 틀릴 수 있는 지점을 짚는다.
2. **주장마다 출처를 단다.** 논문 제목, 저자, 학술지, 연도, DOI 또는 링크. 검색으로 확인한 것과 기억에 의존한 것을 구분해서 표시한다. 확인하지 못한 서지는 "미확인"이라고 적는다.
3. **확인된 사실, 문헌의 주장, 추측을 섞지 않는다.** 한 논문의 주장을 분야의 합의처럼 말하지 않는다.
4. **아이디어마다 세 가지를 따진다.**
   - 이미 누가 했는가 (선행 연구)
   - 우리 파이프라인으로 계산할 수 있는가, 비용은 얼마인가
   - 결과가 예상과 반대로 나오면 무엇을 알게 되는가
5. **채점 정의는 건드리지 않는다.** 새 지표는 우선 보고용 컬럼으로 제안한다. 채점에 넣는 것은 사용자 승인 사항이다.
6. 한국어, 존댓말, 간결하게. 그림이 필요하면 편집 가능한 pptx로.

## 5. 문헌 탐색 질문 (여기서부터 시작)

사용자가 골라서 Claude에게 검색을 시킬 질문들이다.

**메커니즘**
- O3→P3 전이를 늦추는 원소와 그 이유를 실험으로 보인 논문은 무엇인가. 원소 종류별로 설명이 다른가.
- 고엔트로피 층상 산화물에서 "엔트로피 안정화"가 실제로 엔트로피 때문이라는 증거가 있는가, 아니면 특정 원소의 효과인가.
- 0 K DFT가 HEO의 전이 지연을 재현하지 못한다는 보고가 있는가. 있다면 무엇으로 설명하는가.

**성능의 다른 축**
- O3형과 P2형의 Na 확산 계수 비교, 그리고 도핑으로 O3의 확산을 개선한 사례.
- 고엔트로피 조성에서 용량과 수명의 대가 관계를 정량적으로 다룬 논문.
- O3형 소듐 양극재의 공기 안정성을 개선한 원소와 메커니즘.

**방법론**
- MLIP로 층상 산화물의 상전이 또는 이온 확산을 계산한 사례와 그 검증 방법.
- 범용 MLIP의 체계적 오차(연화)가 상 안정성 차이 같은 에너지 차분에 미치는 영향.
- 무질서 고용체의 유한 온도 자유에너지를 MLIP로 구하는 방법.

**경쟁 연구**
- 소듐 층상 양극재를 대상으로 한 고처리량 계산 스크리닝이 이미 있는가. 그들의 기준과 우리 기준의 차이는.
